# Deep Learning Laboratory (30 Scenario-Based Experiments)

This repository contains comprehensive Jupyter Notebook implementations for 30 scenario-based experiments in Deep Learning, covering mathematical foundations, deep neural architectures, recurrent models, linear factor & probabilistic graphical models, and generative models.

All notebooks include fully executed cell outputs, evaluation metrics, and visualizations, along with direct Google Colab launch buttons.

## Getting Started

### Option 1: Run in Google Colab
Click on any **Open In Colab** badge in the table above or directly inside the individual .ipynb files.

### Option 2: Run Locally
1. Clone the repository:
   `ash
   git clone https://github.com/<your-username>/Deep-Learning.git
   cd Deep-Learning
   `
2. Install dependencies:
   `ash
   pip install -r requirements.txt
   `
3. Launch Jupyter Lab:
   `ash
   jupyter lab
   `

### Customizing Badges for Your Own GitHub Account
To point all Colab badges to your own GitHub username, run:
`ash
python update_colab_links.py <your-github-username> [repo-name]
`
